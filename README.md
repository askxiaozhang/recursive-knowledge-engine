# 知识递归学习引擎 (Recursive Knowledge Engine)

这是一个基于“云端鉴权 + 本地执行”架构的智能知识图谱与学习辅助系统。用户通过与 AI 对话，系统自动提取专业术语并动态构建私有的知识网络。

## 核心特性

- **递归学习与自动建网**：通过与 AI 的深度对话，自动识别概念间的逻辑关系并可视化。
- **沉浸式对话界面**：类似 ChatGPT 的交互体验，左侧实时渲染知识图谱。
- **云端鉴权体系**：支持免费版、基础版、专业版三个权限等级，通过卡密（API Key）快速升级。
- **私有数据本地化**：知识点、对话历史和领域关系均存储在本地 `local.db`，确保用户隐私。
- **单日云端备份**：支持将本地学习成果备份至云端，防止数据丢失（每日限 1 次）。

## 架构说明

系统由两个独立部分组成：
1.  **云端鉴权服务器 (`cloud_server.py`)**：处理用户账号、权限配置、卡密兑换及备份存储。
2.  **本地执行端 (`app.py`)**：处理 AI 对话逻辑、本地数据库存储及 UI 渲染。

## 快速上手

### 1. 环境准备
确保已安装 Python 3.8+，并安装依赖：
```bash
pip install flask flask-cors requests
```

### 2. 启动云端服务器
```bash
python cloud_server.py
```
默认运行在 `http://127.0.0.1:5001`。首次启动会自动生成 `cloud.db` 并初始化默认权限与测试卡密（如 `BASIC-123`, `PRO-888`）。

### 3. 启动本地执行端
```bash
python app.py
```
访问 `http://127.0.0.1:5000` 即可开始使用。

## 开发协作

-   **前端**: 使用原生 HTML/JS/CSS，集成 `vis-network` 进行图谱渲染。
-   **后端**: Flask 框架，搭配 SQLite 数据库。
-   **通信**: 本地端通过 `requests` 库与云端进行鉴权与备份交互。
